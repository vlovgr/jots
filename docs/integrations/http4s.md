# http4s

The `jots-http4s` module provides an integration with [http4s](https://http4s.org) clients and servers. On the client side, there is support for refreshing verification by periodically fetching a `JwkSet` from an HTTP endpoint. While on the server side, there's an `AuthMiddleware` for verifying and decoding tokens in incoming requests.
