jots.JwtEncoder
See theJwtEncoder companion object
trait JwtEncoder[A]

Encodes instances of type A to JwtBuilders.

A common approach is to encode instances of type A as the claims of a JwtBuilder. This can be done by defining an Encoder.AsObject instance and then using JwtEncoder.encodeClaims.
